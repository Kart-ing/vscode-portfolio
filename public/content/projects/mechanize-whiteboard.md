# Collaborative Whiteboard

> Real-time multiplayer whiteboard, built as a timed take-home.

**Role:** Solo · **Year:** 2026 · **Status:** Live (interview submission)
**Links:** [GitHub](https://github.com/mechanize-work-interview/takehome-kartikey-pandey) · [Live](https://app-production-e11f.up.railway.app)

## The Problem
Build a production-quality, real-time collaborative canvas under time pressure — the kind of multiplayer surface where several people draw together without stepping on each other.

## What I Built
A multi-user whiteboard with **live remote cursors** and a full shape toolkit — rectangle, ellipse, line, and text — plus select, move, resize, delete, and color. It supports undo/redo, user accounts (signup/login), canvas invitations, and state that persists across sessions. Built in a few hours for a take-home.

## Tech Stack
`React 19` · `TypeScript` · `Vite` · `Node.js` · `PostgreSQL` · `Docker Compose` · `Railway` · `Vercel`

## Highlights
- Real-time multi-user cursor sync
- Persistent canvas state across sessions
- Full auth plus canvas invitations
- Shipped end-to-end in a few hours
