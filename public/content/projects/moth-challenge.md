# NASA Lunar Autonomy Challenge

> Autonomous lunar rover navigation for NASA's LSII (via JHU APL).

**Role:** Machine Learning Engineer, Lunar Autonomy Challenge team (NASA-affiliated, run by Johns Hopkins APL) · **Year:** 2024–2025 (Nov 2024 – Jan 2025) · **Status:** Selected / Completed

## The Problem
Lunar surface robots must navigate, excavate, and use resources entirely autonomously — there's no real-time joystick from Earth. Getting that right in a simulated lunar environment is the prerequisite to doing it for real.

## What I Built
Selected for the NASA-affiliated **Lunar Autonomy Challenge**, run by the **Johns Hopkins University Applied Physics Laboratory (JHU APL)**. Developed autonomous robotics for navigation, excavation, and resource utilization using **CARLA simulation**, **SLAM** algorithms, and AI/ML frameworks — work in support of NASA's **Lunar Surface Innovation Initiative (LSII)**.

## Tech Stack
`Python` · `CARLA simulation` · `SLAM` · `AI / ML frameworks`

- SLAM-based autonomous navigation
- Lunar excavation and resource-utilization research
