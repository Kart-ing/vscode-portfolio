# Project Elementals

> Multiplayer Avatar-inspired AR game on Snap Spectacles.

**Role:** Lead AR Developer, Team Virtus · **Year:** 2025 · **Status:** Funded (Snap Spectacles Accelerator)

## The Problem
Shared, physical-feeling multiplayer AR experiences are rare. Most AR is single-player and ephemeral — there's little that lets people in the same room share one persistent, interactive world.

## What I Built
A multiplayer AR game where players become **elemental benders** in a shared AR environment, with real-time synchronization across Spectacles devices so everyone sees the same world react together. Built by Team Virtus as part of the **$25,000+ Snap Spectacles Student Accelerator** funding.

## Tech Stack
`Lens Studio` · `TypeScript` · `Node.js` · `Real-time cloud sync`

## Highlights
- Multiplayer **shared AR** across devices
- Real-time state synchronization
- Part of the **$25k+** Snap Spectacles Accelerator funding
