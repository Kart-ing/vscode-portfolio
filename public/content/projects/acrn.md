# ACRN

> Brand site for a hacker house — botanical-press meets terminal.

**Role:** Design + Build · **Year:** 2026 · **Status:** Live
**Links:** [Live](https://acrn.space)

## The Problem
A hacker house needed a distinctive homepage and member directory — something that felt hand-made and rooted, not another framework template.

## What I Built
A hand-authored static site with a bespoke **Material Design 3** color system themed around nature — soil, moss, acorn, fern, clay. Three typographic voices (**Fraunces**, **Newsreader**, **JetBrains Mono**) give it a botanical-press-meets-terminal feel, laid out as scrollable "field notes." It ships full OG/SEO meta and 8 member profiles, in a ~35KB hand-written `index` with no framework.

## Tech Stack
`HTML5` · `CSS (Material Design 3 tokens)` · `Vanilla JS` · `Python (palette-gen scripts)` · `Vercel`

## Highlights
- Bespoke **MD3 botanical palette** (soil / moss / acorn / fern / clay)
- Three-voice typography: Fraunces, Newsreader, JetBrains Mono
- 8-member team directory with full OG/SEO meta
- Zero-framework, ~35KB hand-authored index
